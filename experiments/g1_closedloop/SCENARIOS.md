# G1 클로즈드루프 — 물리 주행 시나리오

DeepSEE(센서)와 이미지규칙이 **둘 다 약한 sensor-blind 구간**을 의도적으로 설계해,
운영자 자연어 주입(HDS)이 드리프트를 줄이는 효과를 측정한다.
조건 C0(완화없음)/C1(DeepSEE-only)/C2(HDS full) × 반복 R≥5. 평가: `traj_eval.py`.

> 핵심: 각 시나리오는 **카메라엔 정상으로 보이지만 SLAM이 깨지는** 상황 + **사람만 아는 사전지식**을 갖는다.
> 운영자는 구간 진입 *전*에 자연어를 입력(`hds_g1_local` 콘솔). C2에서만 이 입력이 반영된다.

| 측정 | 도구 |
|---|---|
| ATE / RPE (vs reference) | `traj_eval.py est.tum ref.tum --align sim3` |
| 추적실패 횟수·시간 | ORB-SLAM3 tracking state 로그 |
| 경보 lead-time, 완화 개입 | `mitig_log_*.csv`, `hds_log_*.csv` |

---

## S1. 반복 텍스처 복도 (개방어휘)
- **셋업**: 동일 타일/벽지 패턴이 길게 반복되는 복도를 직진 주행.
- **센서 맹점**: 특징점은 풍부(밝기·블러 정상) → DeepSEE·G 저위험 판정. 그러나 반복 패턴이 위치 모호성 유발 → 실제 드리프트/오매칭.
- **운영자 입력 예**: "이 복도는 양쪽 벽 무늬가 똑같아서 위치를 자주 헷갈릴 거야."
- **기대**: C2가 사전 감속/키프레임↑로 오매칭 감소 → C1·C0 대비 ATE 감소.

## S2. 유리벽 / 거울 구간 (개방어휘)
- **셋업**: 유리 파티션·전면 거울이 있는 로비/복도 통과.
- **센서 맹점**: 영상은 선명 → 규칙·DeepSEE 저위험. 반사로 가짜 특징·깊이 오류 발생.
- **운영자 입력 예**: "앞에 유리벽이라 반사로 특징점이 가짜로 잡힐 거야."
- **기대**: C2 감속+relocalization 대비로 추적실패 감소.

## S3. 동적 보행자 밀집 (개방어휘)
- **셋업**: 사람이 지나다니는 통로/홀.
- **센서 맹점**: 정적 프레임 특징 충분 → 저위험 판정. 움직이는 사람이 매칭 흔듦.
- **운영자 입력 예**: "앞 구간 사람들이 계속 지나다녀서 추적이 흔들릴 거야."
- **기대**: C2 감속으로 동적 객체 영향 완화.

## S4. 무텍스처 벽/천장 (개방어휘)
- **셋업**: 단조로운 흰 벽·천장을 향해 주행/회전.
- **센서 맹점**: 평균 밝기 정상 → 규칙 저위험. 특징 거의 없음 → 추적 빈약.
- **운영자 입력 예**: "이쪽은 흰 벽뿐이라 특징이 거의 안 잡혀."
- **기대**: C2 사전 키프레임↑/감속.

## S5. 역광 모퉁이 — 사전지식 (합성·인과)
- **셋업**: 특정 시간대 창문 역광이 드는 모퉁이를 회전.
- **센서 맹점**: 진입 *전* 현재 프레임은 정상 → DeepSEE 저위험. 회전 순간 역광으로 노출 폭주.
- **운영자 입력 예**: "지난번 여기 모퉁이 돌 때 역광에 놓쳤는데 오늘도 같은 시간이야."
- **기대**: C2만 사전 대비 가능(센서·규칙은 아직 안 보임) → 핵심 차별 케이스.

## S6. 어두워 보이지만 안전 — 위험 하향 (음의 δ)
- **셋업**: 잠깐 그늘/검은 현수막 등 *일시적*으로 어두운 구간(실제 추적엔 무해).
- **센서 맹점**: 밝기 저하 → DeepSEE·G가 **과경보**. 실제론 안전.
- **운영자 입력 예**: "어두워 보이지만 잠깐 그늘이고 바로 밝아져서 괜찮아."
- **기대**: C2가 **불필요한 감속/경보를 억제**(−δ) → C1 대비 **개입 횟수↓, 주행 효율↑** (오경보 비용 감소).
- **주의**: 이 시나리오는 ATE가 아니라 **오경보/불필요 완화 감소**로 평가. DeepSEE·규칙은 구조적으로 못 함.

## S7. 대조군 — 명백 정상 구간
- **셋업**: 조명 양호·텍스처 풍부·정적 환경 직진.
- **기대**: 세 조건 모두 유사(완화 거의 없음). 시스템이 정상 구간에서 헛개입 안 함을 확인(특이도).
