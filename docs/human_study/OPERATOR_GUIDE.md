# 운영자 안내 (Operator Guide) — 시나리오 작성

당신은 SLAM 로봇을 원격 감독하는 운영자입니다. 로봇이 **앞으로 지나갈 구간의 영상/경로 미리보기**를 보고,
드리프트(추적 실패) 위험에 대해 **평소 말하듯 자유롭게 한국어로** 적어 주세요.

## 중요 원칙
- **에러 수치나 정답을 보지 마세요.** 오직 영상·경로·당신의 사전지식만으로 판단합니다.
- **자유 서술하세요.** "어둡다" 같은 단어를 쓰라는 게 아니라, *당신이 아는 것*을 자연스럽게 말하세요.
- 다음 4종을 의식적으로 섞어 주세요 (각 ≥3개씩, 총 ≥40문장 목표):

| 유형 | 예시 상황 | 자유 서술 예 |
|---|---|---|
| **개방어휘** (카메라엔 멀쩡한데 위험) | 반복 무늬, 동적 객체, 무텍스처 | "양쪽 벽이 똑같은 타일이라 위치를 헷갈릴 듯" |
| **위험 하향** (위험해 보이지만 안전) | 일시적 그늘, 적외선 조명 | "어두워 보이지만 곧 밝아져서 괜찮아" |
| **합성·인과·사전지식** | 과거 경험, 미래 상태 | "지난주 여기 모퉁이에서 놓쳤는데 오늘도 같은 시간이야" |
| **부정문** | 위험 부재 강조 | "전혀 어둡지 않고 급회전도 없어" |

## 작성 방법
`templates/scenarios_raw.csv`에 한 줄씩:
```
scenario_id, operator_id, clip_ref, free_text
S001, P1, route_A_seg03, "양쪽 벽 타일 무늬가 똑같아서 위치를 자주 헷갈릴 거야"
```
- `scenario_id`: S001~ 순번 (운영자 간 겹치지 않게)
- `operator_id`: 본인 식별자 (P1, P2, …)
- `clip_ref`: 본 영상/구간 식별자
- `free_text`: 자유 서술 (쉼표 포함 시 큰따옴표로 감쌀 것)
