# 전문가 라벨링 안내 (Expert Labeling Guide) — 정답(GT) 부여

당신은 V-SLAM 전문가입니다. 각 운영자 서술이 **드리프트 위험을 어떻게 조정해야 하는지** 정답을 라벨합니다.

## 라벨 척도 (5단계 — 카테고리)
| label | 의미 | 대응 risk_delta 밴드 |
|---|---|---|
| `strong_inc` | 강한 위험 증가 | [+0.30, +0.50] |
| `mild_inc` | 약한 위험 증가 | [+0.10, +0.30] |
| `neutral` | 중립 (조정 불필요) | [−0.10, +0.10] |
| `mild_dec` | 약한 위험 감소 (센서 과경보) | [−0.30, −0.05] |
| `strong_dec` | 강한 위험 감소 | [−0.50, −0.20] |

## 원칙
- **서술 내용만으로 판단** (운영자가 누구인지, LLM/규칙 답이 뭔지 보지 마세요).
- 위험을 *낮추는* 방향(`*_dec`)도 적극 사용 — 센서가 과경보하는 상황을 운영자가 바로잡는 경우.
- 각 전문가는 **독립적으로** 라벨합니다. 합의는 분석 단계에서 처리(불일치 시 토론).

## 작성 방법
`templates/gt_labels.csv`에:
```
scenario_id, expert_id, label
S001, E1, mild_inc
S001, E2, strong_inc
```
- 모든 `scenario_id`를 각 전문가가 1회씩 라벨.
- 분석 스크립트가 **다수결 합의 + Fleiss κ(전문가 일치도)**를 자동 계산합니다.
