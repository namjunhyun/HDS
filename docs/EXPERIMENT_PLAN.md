## 0. 논문 주장 (thesis)

> **신경 드리프트 예측기는 새 도메인으로 zero-shot 전이가 잘 안 된다.
> 가벼운 휴먼-인-더-루프 신경-기호 레이어가 도메인 밖 배포에서 조기경보 신뢰성을 복구한다.**

핵심은 "정확도 자랑"이 아니라 **"드리프트를 헛경보 없이 몇 초 일찍 잡는다(proactive anticipation)"**.

---

## 1. 평가 역할 분담

| | 데이터 | 역할 | 증명 |
|---|---|---|---|
| **In-domain** | SenseTime (test fold) | base 타당성 | DeepSEE가 자기 도메인에서 작동 (AUC) |
| **Zero-shot** | EuRoC (+TUM-VI/OpenLORIS) | 정량 검증대 | 도메인시프트 저하 + HDS 복구, lead-time |
| **실로봇** | Unitree G1 | 라이브 배포 | 실시간 동작 + 클로즈드루프(완화→ATE↓) |

G1엔 정밀 드리프트 GT가 없으므로(모캡 부재), **정량 lead-time은 EuRoC**(정확 GT)로, **실배포 효용은 G1**으로 나눠 증명.

## 2. 평가 방법론 (공정성 — 리뷰어 방어)

- **이벤트 정의**: `Y_gt > τ` 절대 임계 (τ ∈ {4.2, 4.6, 5.0} 스윕). 시퀀스별 정규화로 인한 **가짜 이벤트 없음**.
- **점수 정규화**: **causal**(과거만) — 온라인 조기경보에 미래값 누수 없음. 배포충실 비교로 고정캘리브도 병기.
- **지표 (재현율만 부풀리기 차단)**: EWR@{1,3,5}s, **Precision**, **False-Alarm/min**, **alert duty%**, mean-lead, AUC-ROC/PR.
- **어노테이션**: 에러 GT 안 보고 *이미지 관측 단서*(어두움/텍스처/회전)로만 배치, 구간보다 LEAD 앞서서(경로 사전지식). → 이전 오라클 배치의 누수 제거.
- **통계**: 이벤트 부트스트랩 95% CI.
- **재현성**: 결정론적(고정 seed), LLM temperature=0 + 응답 캐싱, API 없이도 폴백으로 실행 가능.

## 3. 현재까지 결과 (2026-06-12, `eval/eval_offline.py`)

### In-domain (SenseTime) — base 타당성 ✅
- **AUC-ROC = 0.803 (95% CI 0.777–0.828)**, fold별 0.63–0.90.
- → base 모델은 견고. EuRoC zero-shot 저하는 도메인시프트지 결함 아님.

### EuRoC zero-shot, τ=4.6, THR=0.85, H=8s (이벤트 47)
| Variant | EWR@1 | EWR@5 | Precision | FA/min | mean-lead | recall 95%CI |
|---|---|---|---|---|---|---|
| DS (base) | 46.8% | 31.9% | 60.0% | 1.06 | 6.0s | [31.9–61.7] |
| DS+G | 61.7% | 42.6% | 61.0% | 1.41 | 6.4s | [48.9–74.5] |
| DS+Sym | 51.1% | 36.2% | 62.5% | 1.06 | 6.2s | [38.3–63.8] |
| **Full** | **68.1%** | **55.3%** | 61.7% | 1.58 | **6.8s** | [57.4–83.0] |

**Full이 DS 대비 동일 정밀도에서 recall +21%p, lead +0.8s.**

### 정직한 한계
- zero-shot AUC ~0.5–0.56 (modest). 절대 성능은 강하지 않음.
- 이벤트 47개라 **CI 일부 겹침** → 약한 유의성. 표본 확대 필요.
- causal 모드에선 **G > Sym 기여** → LLM 당위성 별도 입증 필요(아래 5).

## 3-bis. 게이트 실험: LLM이 규칙을 이기는가 (2026-06-12, `eval/gate_llm_vs_rules.py`)

sensor-blind 시나리오 11개(DeepSEE·이미지규칙 모두 실패하도록 설계)에서 자연어 → risk_delta:
- **규칙 전체정확도 45% vs LLM 100%**, 규칙 실패 6건 중 **LLM 100% 복구**.
- 규칙이 원리적으로 못 푸는 4종을 LLM이 전부 처리: 개방어휘 / 위험하향(−델타) / 합성·인과 / 부정문.
- → **LLM 기여는 장식이 아니라 구조적.** 헤드라인을 "센서가 못 보는 지식의 자연어 주입"으로 확정.

**⚠ 한계(자기충족 위험)**: 시나리오·정답·LLM답을 모두 저자가 생성. go/no-go 신호로는 유효하나
논문 증거가 되려면 **운영자 작성 시나리오 + 합의 정답 라벨 + 제3자 규칙 튜닝**(human study)으로 격상 필수.
